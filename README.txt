WorkBoard — application de tâches professionnelles pour tablette.

Fonctions :
- tâches professionnelles cochables au doigt
- priorités haute / normale / basse
- filtres Toutes / À faire / Terminées
- progression automatique
- compteur de tâches
- notes de travail
- sauvegarde locale sur l'appareil
- fonctionnement hors ligne après installation

Pour l'installation comme application sur tablette : ouvrir index.html via un hébergement HTTPS puis choisir « Ajouter à l'écran d'accueil » dans le navigateur.
